# CLAUDE.md

This repo is a guided tour of the Radiant monorepo POC, one chapter per branch (`poc/monorepo-NN-*`, see README.md).
When the user wants the tour, or asks what this repo is for, use the `tour` skill (`/tour`).

Local only: never push, never use `gh`, never run the GitHub workflows. Never read `.env` files or secrets.
Module internals (backend, frontend...) are copies of the real repos: their own conventions do not apply here.
