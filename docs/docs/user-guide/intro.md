# User guide

This guide explains how to use the Radiant portal to explore the cases, variants and files of your genomic analyses. If you are new to the portal, start with [Getting started](./getting-started/portal-overview.md).

## How to use this guide {/* #how-to-use */}

The menu on the left lists the sections of the guide. Each page answers a single question, and its title tells you which:

| If the title… | the page… | Example |
|---|---|---|
| starts with a verb | describes a procedure, step by step | Sign in and sign out |
| names an element of the portal | explains what it is and what it is for | Portal overview |
| names a list of elements | describes each column, filter or value in a table | Case table columns |
| describes a problem | gives its cause and its solution | The download fails |

Pages always have the same sections, in the same order. At the bottom of each page, **See also** lists the pages that logically come next.

The guide is available in English and French. To change the language, use the language menu at the top right.

## Writing conventions {/* #conventions */}

| Format | Meaning | Example |
|---|---|---|
| **Bold** | A label on the screen, written exactly as in the portal: button, tab, field, menu | Click **Sign out**. |
| **Bold › Bold** | A path to follow through the menus | **Admin › Members** |
| `Monospace` | Text to type, a value or a file name | Enter `BRCA1`. |
| <kbd>Key</kbd> | A keyboard key | <kbd>Enter</kbd> |
| "Quotes" | A message shown by the portal | The "Filter saved" message appears. |
| (Optional) | A step you can skip | |

Screenshots sometimes carry numbered pins. Their numbers match the steps of the procedure.

## Callouts {/* #admonitions */}

Some information is highlighted in a callout. Each type of callout has its own color, icon and meaning.

:::info[Before you begin]
What you need to have or prepare before following a procedure: a role, a starting page, data.
:::

:::note
A useful but secondary detail. You can skip it and still succeed.
:::

:::tip
A faster or more convenient way to reach the same result.
:::

:::warning
A risk of losing your work in progress or getting an unexpected result.
:::

:::danger
An irreversible action, or a risk to the confidentiality of patient data. Read it before you continue.
:::

## Badges {/* #badges */}

Under the title of a page, a badge tells who or what the page applies to:

- <span className="badge badge--primary">Admin</span> the page covers a feature reserved for administrators;
- <span className="badge badge--warning">Beta</span> the feature is under development and may change.
