# Navigate the portal

The bar at the top of the screen gives access to every section of the portal and to your settings.

## The navigation bar {/* #navigation-bar */}

| Area | Element | Purpose |
|---|---|---|
| Left | Logo and network name | The network whose data you are viewing. |
| Center | **Cases** | The list of cases. |
| | **File Archive** | The files of all cases. |
| | **Admin** | The management of users, roles and organizations. Visible to administrators only. |
| Right | Your avatar | Your name, your email and **Sign out**. |
| | **FR** or **EN** | The interface language. See [Change the language and theme](./language-and-theme.md). |
| | Moon or sun | The light or dark theme. |

On a narrow screen, such as a phone, the sections are grouped in a menu. Tap the menu icon at the top left to open it.

## Switch network {/* #switch-network */}

If you have access to several networks, the network name is followed by a small arrow.

1. At the top left, click the network name.
2. In the **Switch Tenant** list, select a network.

The portal shows the data of the selected network. A check mark shows the active network.
