# Portal overview

The Radiant portal lets you review genomic cases, explore their variants and access their files.

## What you find there {/* #what-you-find */}

| Section | Content |
|---|---|
| **Cases** | The cases you have access to. Each case gives access to its variants, SNV and CNV, and to its files. This is the portal's home page. |
| **File Archive** | The files produced by the analyses, across all cases. |
| **Admin** | The management of users, roles and organizations. Visible to administrators only. |

## Networks {/* #networks */}

The portal's data is split into networks: separate, private data spaces. The name of the network you are viewing shows at the top left, next to the logo. You only see the data of the networks you have access to.

If you have access to several networks, you can switch between them. See [Navigate the portal](./navigate.md#switch-network).
