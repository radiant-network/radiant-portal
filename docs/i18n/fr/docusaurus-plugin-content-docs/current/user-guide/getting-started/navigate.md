# Naviguer dans le portail

La barre en haut de l'écran donne accès à toutes les sections du portail et à vos réglages.

## La barre de navigation {/* #navigation-bar */}

| Zone | Élément | Rôle |
|---|---|---|
| À gauche | Logo et nom du réseau | Le réseau dont vous consultez les données. |
| Au centre | **Cas** | La liste des cas. |
| | **Archive de fichiers** | Les fichiers de tous les cas. |
| | **Admin** | La gestion des utilisateurs, des rôles et des organisations. Visible seulement pour les administrateurs. |
| À droite | Votre avatar | Votre nom, votre courriel et **Se déconnecter**. |
| | **EN** ou **FR** | La langue de l'interface. Voir [Changer la langue et le thème](./language-and-theme.md). |
| | Soleil ou lune | Le thème clair ou sombre. |

Sur un écran étroit, comme un téléphone, les sections sont regroupées dans un menu. Touchez l'icône de menu en haut à gauche pour l'ouvrir.

## Changer de réseau {/* #switch-network */}

Si vous avez accès à plusieurs réseaux, le nom du réseau est suivi d'une petite flèche.

1. En haut à gauche, cliquez sur le nom du réseau.
2. Dans la liste **Changer de tenant**, sélectionnez un réseau.

Le portail affiche les données du réseau choisi. Une coche indique le réseau actif.
