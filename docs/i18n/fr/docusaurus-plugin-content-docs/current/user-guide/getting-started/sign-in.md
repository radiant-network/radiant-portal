# Se connecter et se déconnecter

Connectez-vous avec le compte Radiant que vous a fourni votre organisation.

:::info[Avant de commencer]
Vous avez l'adresse du portail et un compte Radiant actif. Sinon, communiquez avec l'administrateur Radiant de votre organisation.
:::

## Se connecter {/* #sign-in */}

1. Ouvrez l'adresse du portail dans votre navigateur.
2. Sur la page de connexion, saisissez votre identifiant et votre mot de passe.
3. Validez.

La page **Cas** s'affiche.

Si votre session expire pendant que vous travaillez, le portail vous renvoie à la page de connexion. Une fois reconnecté, vous revenez à la page où vous étiez.

## Se déconnecter {/* #sign-out */}

1. En haut à droite, cliquez sur votre avatar.
2. Cliquez sur **Se déconnecter**.

La page de connexion s'affiche.

## Le message « Vous n'avez pas accès à RADIANT » {/* #no-access */}

Votre compte existe, mais il n'est rattaché à aucun réseau. Communiquez avec l'administrateur Radiant de votre organisation pour obtenir l'accès, puis cliquez sur **Retour à la connexion**.
