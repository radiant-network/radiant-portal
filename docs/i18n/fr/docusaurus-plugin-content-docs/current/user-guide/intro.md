# Guide utilisateur

Ce guide explique comment utiliser le portail Radiant pour explorer les cas, les variants et les fichiers de vos analyses génomiques. Si vous découvrez le portail, commencez par [Premiers pas](./getting-started/portal-overview.md).

## Comment utiliser ce guide {/* #how-to-use */}

Le menu de gauche liste les sections du guide. Chaque page répond à une seule question, et son titre l'annonce :

| Le titre… | La page… | Exemple |
|---|---|---|
| commence par un verbe | décrit une marche à suivre, étape par étape | Se connecter et se déconnecter |
| nomme un élément du portail | explique ce qu'il est et à quoi il sert | Présentation du portail |
| nomme une liste d'éléments | décrit chaque colonne, filtre ou valeur dans un tableau | Colonnes du tableau des cas |
| décrit un problème | en donne la cause et la solution | Le téléchargement échoue |

Les pages ont toujours les mêmes sections, dans le même ordre. En bas de chaque page, **Voir aussi** propose les pages qui suivent logiquement.

Le guide est disponible en français et en anglais. Pour changer de langue, utilisez le menu des langues en haut à droite.

## Conventions d'écriture {/* #conventions */}

| Présentation | Signification | Exemple |
|---|---|---|
| **Gras** | Un libellé de l'écran, écrit exactement comme dans le portail : bouton, onglet, champ, menu | Cliquez sur **Se déconnecter**. |
| **Gras › Gras** | Un chemin à suivre dans les menus | **Admin › Membres** |
| `Chasse fixe` | Un texte à saisir, une valeur ou un nom de fichier | Saisissez `BRCA1`. |
| <kbd>Touche</kbd> | Une touche du clavier | <kbd>Entrée</kbd> |
| « Guillemets » | Un message affiché par le portail | Le message « Filtre enregistré » s'affiche. |
| (Facultatif) | Une étape que vous pouvez sauter | |

Les captures d'écran portent parfois des pastilles numérotées. Leurs numéros correspondent aux étapes de la procédure.

## Les encadrés {/* #admonitions */}

Certaines informations sont mises en évidence dans un encadré. Chaque type d'encadré a sa couleur, son icône et un sens précis.

:::info[Avant de commencer]
Ce qu'il faut avoir ou préparer avant de suivre une procédure : un rôle, une page de départ, des données.
:::

:::note
Une précision utile mais secondaire. Vous pouvez l'ignorer et réussir quand même.
:::

:::tip
Une façon plus rapide ou plus pratique d'arriver au même résultat.
:::

:::warning
Un risque de perdre votre travail en cours ou d'obtenir un résultat inattendu.
:::

:::danger
Une action irréversible, ou un risque pour la confidentialité des données des patients. Lisez-le avant de continuer.
:::

## Les badges {/* #badges */}

Sous le titre d'une page, un badge indique à qui ou à quoi elle s'applique :

- <span className="badge badge--primary">Admin</span> la page concerne une fonction réservée aux administrateurs ;
- <span className="badge badge--warning">Bêta</span> la fonction est en cours de développement et peut changer.
